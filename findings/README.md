# findings/

A buffer for things unattended or exploratory runs notice: perf deltas, drift, flaky tests, suspicious code.

- Append, do not auto-fix. One file per area (for example `perf.md`, `drift.md`).
- Each entry: date, what was seen, evidence (command output or path), suggested next step.
- A human reviews the buffer every few days and turns items into task cards or friction-log rows.
