# Task card

One job per card. Permanent rules live in `AGENTS.md` and the agent definition; do not repeat them here.

```
TASK         <result first, one sentence>
OWNER        <one agent that owns the outcome>
SOURCES      <files, issues, docs that are the source of truth>
MAY CHANGE   <paths/systems>
MAY NOT      <paths/systems>
STOP BEFORE  <first one-way-door step>
DONE WHEN    <command(s) that must pass + artifacts required>
RETURN       <PR link, check output, screenshots/FLIP map, summary; hand off to @owner>
```
